# MeshVoice

**Learning Without Limits.**

MeshVoice is an open-source project focused on local-network audio streaming for classrooms, educational environments, and emergency shelters.

## Project status

MeshVoice is maintained on a bug-fix basis. The maintainer intends to focus on correcting reproducible bugs, improving reliability, and addressing security issues rather than actively developing new features.

## Contributions

Bug reports and reproducible test cases are welcome. Before submitting an issue, please check whether the problem has already been reported.

Feature requests may be considered, but new features are not guaranteed to be implemented.

## Goals

- Reliable audio transmission over a local network.
- Usability in environments with limited or no internet access.
- A lightweight and maintainable codebase.
- Open and transparent development.
